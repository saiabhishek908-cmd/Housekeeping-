HOUSEKEEP V0.2 — PWA

This is an installable Progressive Web App prototype.

To install on Android:
1. The files must be hosted on HTTPS (a local content:// file cannot be installed as a PWA).
2. Open the hosted site in Chrome.
3. Use Chrome's Install app / Add to Home screen option.

Current features:
- Customer booking screen
- Service selection
- Duration
- Number of workers
- Demo price calculation
- Demo booking status
- PWA manifest
- Basic offline service worker

Next:
Customer + worker accounts, real backend, worker availability/matching, maps, payments, notifications.
